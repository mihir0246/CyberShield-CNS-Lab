    Promiscuous vs Non-Promiscuous Capture Modes
    Standard / Non-Promiscuous Mode

    NIC hardware filters incoming Ethernet frames. Frames not addressed to the host's unicast MAC address (or broadcast/multicast) are discarded at the physical PHY layer.

    Promiscuous Mode

    NIC passes all frames on the physical wire up to the kernel packet filter driver (Npcap / WinPcap / libpcap).

    Critical Network Reality: On modern switched LANs, Ethernet switches direct unicast traffic only to the recipient's specific switch port based on CAM tables. Thus, promiscuous mode on a normal host will not capture other workstations' traffic unless port mirroring (SPAN), a network TAP, or ARP cache poisoning is used.
