    Project Overview

    CyberShield is an enterprise-grade, academically presentable educational laboratory web platform designed specifically for the Cryptography and Network Security (CNS) laboratory curriculum in Computer Science and Cybersecurity Engineering programs.

    Unlike static dashboards or disconnected script collections, CyberShield consolidates all 9 core practical experiments into a single cohesive platform featuring modular Flask Blueprints, real cryptographic libraries (`cryptography`, standard library `hashlib`), Scapy deep packet inspection, controlled Nmap subprocess wrappers with strict target whitelist guards, and Snort IDS rule/alert ingestion.

    Engineering Syllabus Mapping
    Exp # Laboratory Module Primary Technology & Standard
    EXP 1 Classical Cryptographic Techniques Caesar (Shift mod 26), Vernam One-Time Pad (XOR), Rail Fence (Transposition)
    EXP 2 Hill Cipher Matrix multiplication modulo 26, modular inverse matrix via extended Euclidean algorithm
    EXP 3 RSA Public-Key Cryptosystem RFC 8017 PKCS#1 v2.2 RSA-OAEP with SHA-256 and key size benchmarks
    EXP 4 Diffie–Hellman Key Exchange RFC 3526 MODP Group, HKDF-SHA256 (RFC 5869) key derivation, small-integer math trace
    EXP 5 MD5 Hashing & Integrity Verification MD5 vs SHA-256 empirical performance benchmark suite, collision vulnerability warnings
    EXP 6 Wireshark & Packet Analysis Scapy PCAP/PCAPNG parser, protocol distribution, top talkers, promiscuous mode guide
    EXP 7 Nmap Network Scanning Controlled subprocess wrapper, XML machine parser, target IP whitelisting
    EXP 8 Controlled DoS Analysis Synthetic volumetric queuing simulation, token-bucket defense, Hping3 study guide
    EXP 9 Snort IDS Log & Rule Analyzer Signature rule anatomy explainer, fast-alert log parser, CSV export
    EXP 10 Cross-Lab Event Correlation Temporal fusion engine connecting PCAP packets, Snort alerts, and scan discoveries
    Technology Stack
    • Backend: Python 3.12+, Flask 3.1
    • Database: SQLite with SQLAlchemy 2.1
    • Frontend: Bootstrap 5.3, Bootstrap Icons, Chart.js
    • Cryptography: Python standard library & `cryptography` 44.0
    • Packet Analysis: Scapy 2.6.1
    • Scanning: Nmap with safe argument validation
    • Testing: Automated test suite with `pytest`
