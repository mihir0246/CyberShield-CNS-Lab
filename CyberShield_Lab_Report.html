CyberShield is fully implemented, verified, tested, and operational. It unifies the entire second-year / third-year undergraduate engineering Cryptography and Network Security (CNS) practical syllabus into an academically presentable, full-stack cybersecurity web application. It eliminates disconnected terminal scripts and static mockups in favor of authentic algorithms, mathematical validation, database persistence, and multi-source event correlation.

1. Summary of Implemented Modules

Every laboratory experiment mandated by the academic syllabus is implemented end-to-end with interactive web interfaces, REST APIs, database logging, and unit tests:

5. External Tools Status & Graceful Fallback

Nmap & Snort Detection: When Nmap or Snort are not present in the system PATH, the application automatically activates high-fidelity laboratory sample datasets rather than crashing or displaying empty interfaces:

  • Nmap Network Scanner: Renders complete port discovery, service versions, and state tables parsed directly from authentic Nmap XML output (samples/sample_nmap.xml).
  • Snort IDS Analyzer: Deconstructs real Snort rules and parses fast-alert records from samples/sample_snort.log with priority classification and source/destination IP breakdowns.
  • Live Execution Support: Once Nmap or Snort are installed locally and added to PATH, the platform automatically switches from fallback mode to live execution mode without requiring code changes.

7. Practical Demonstration Sequence for Faculty Presentation

To demonstrate CyberShield during a practical oral examination (Viva Voce), follow this recommended 5-minute walkthrough:

  1. Dashboard Overview (/): Show the 10-module syllabus checklist, active module KPI cards (Runs, Ciphers, PCAPs, Snort alerts), and live system health diagnostics.
  2. Classical Ciphers (/ciphers/): Demonstrate Caesar cipher with character shift trace preserving punctuation and case. Run the Vernam One-Time Pad byte-wise XOR and explain Shannon's perfect secrecy criteria and key non-reuse. Show the Rail Fence zig-zag transposition wave matrix.
  3. Hill Cipher (/hill/): Load the valid 2×2 key matrix (det mod 26 = 9, inv = 3), encrypt "HELP" to "HIAT", and decrypt it back. Then click "Test Non-Invertible Key" to demonstrate mathematical error rejection when gcd(det, 26) ≠ 1.
  4. Modern Asymmetric Cryptography (/rsa/ & /diffie-hellman/): Generate an RSA-2048 keypair, encrypt using OAEP-SHA256, decrypt with private key, and run the key-size latency benchmark chart. Then run the Diffie–Hellman exchange to show Alice and Bob independently deriving identical 256-bit keys via HKDF-SHA256.
  5. MD5 Hashing & Integrity (/hashing/): Contrast MD5 with SHA-256 for text and files. Run the 5-trial benchmark across 1 KB to 5 MB payloads and explain RFC 6151 deprecation of MD5 due to collision attacks.
  6. Wireshark Packet Analysis (/pcap/): Click "Load Sample Lab PCAP" to dissect 13 frames across HTTP, DNS, TCP, and ICMP. Filter by TCP flag SYN to isolate port-probing traffic. Open the Promiscuous Mode Guide to explain switched network CAM table behavior.
  7. Nmap Scanner & Controlled DoS (/nmap/ & /dos/): Demonstrate target whitelisting (show how scanning unauthorized external IPs is blocked). In the DoS lab, run the 15-second simulation with "Enforce Rate Limiting Defense" toggled ON (latency remains capped). Toggle it OFF to demonstrate server latency degradation.
  8. Snort IDS & Event Correlation (/snort/ & /correlation/): In the Snort lab, deconstruct rule syntax (header and options) and ingest sample fast-alert logs. Navigate to /correlation/ and click "Execute Cross-Lab Correlation Engine". Show how it fuses the multi-port SYN probes from the PCAP with the Snort portscan alerts into a verified high-confidence finding.
  9. Lab Manual & Viva Questions (/docs/): Conclude by opening the in-browser Practical Manual and Viva Voce question bank (with 30+ answers) directly inside the application.
